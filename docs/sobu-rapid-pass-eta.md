# 総武快速線の通過駅補完とETA較正

錦糸町〜千葉の通過駅は中央・総武線の既存駅ID（line_cd=11313）を使用する。
停車駅（line_cd=11314）の実効速度100km/hに対し、追加した通過駅は既定の80km/hとなり、
生成データのETA回帰テストで錦糸町→津田沼が22.3分、新小岩→津田沼が17.1分へ延びた。

11313 × Rapid の実効速度を105km/hに較正する。N02の分割距離と通過駅ペナルティを含め、
既存のメンテナ確認値（`travel_times/cases.csv`：典型20分・16分）に合わせた値である。
実際の列車速度を意味する値ではない。既存の11314 × Defaultの100km/hは維持する。
中央・総武線内を各駅停車する東西線直通快速は、通過駅がない路線ではDefaultへ補正する
既存処理により対象外。ほかの種別とLegacyの速度表は変更しない。

# 鹿児島本線の区間快速

2026-10-20 に JR九州の駅別時刻表（2026年10月）で確認した停車パターン。
博多駅の上下方向に掲載された区間快速37列車を確認し、快速区間と竹下・笹原の停車有無で7系統に分ける。
各系統の名称の括弧内は快速運転区間であり、運転区間全体ではない。
種別は545～551、路線グループは1189～1195。既存の快速259や他線区の区間快速108は変更しない。

同じ停車パターンの始終着違いは路線グループに集約する（時刻表・列車単位の運行情報ではない）。
福間～二日市間快速は門司港発鳥栖行と小倉発荒尾行などの共通パターンを集約する。
博多を通り抜ける系統には1190231と1190301の両駅IDを含め、博多止まりの系統には北側のみを含める。
上りのみ確認した4系統はdirection=1、上下を確認した3系統はdirection=0。
折尾まで快速の系統は海老津に停車し、福間まで快速の系統は福間以北で各駅に停車する。

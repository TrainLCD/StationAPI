# 2026年11月21日改正：印西牧の原発三崎口行

## 公式根拠と対象

- [北総鉄道の改正案内](https://www.hokuso-railway.co.jp/newsrelease/detail/75779)：土休日の印西牧の原8:20発を京成高砂まで延長し、三崎口行として運転。
- [京急の改正後連絡時刻表](https://www.keikyu.co.jp/ride/kakueki/pdf/other_holiday2026.pdf) PDF 2ページ／掲載131ページ：836T、印西牧の原8:20→京成高砂8:52着・8:58発→押上9:10→泉岳寺9:35着・9:36発。京成線内は普通で京成立石などにも停車、京急線内は特急、三崎口10:54着。
- [京急本線改正後時刻表](https://www.keikyu.co.jp/ride/kakueki/pdf/mainline_holiday2026.pdf) 掲載81ページ：836Tの京急線内停車駅を確認。

2026年11月17日確認。今回追加するのはこの列車の片方向だけで、印旛日本医大への延長や逆方向の運転は推測しない。

## 実装と既存動作への影響

`5!station_station_types.csv`を前処理・Workerの索引に取り込み、種別候補と系統駅列に供給する既存経路を使用する。APIや検索ロジックは変更しない。

- 新規group1207。印西牧の原→泉岳寺は専用type561「普通(三崎口方面)」、京急線内はtype562「特急(三崎口方面)」。格納順に進む方向だけを示すdirection=2、priority=0。
- 京成高砂（北総・押上線・本線）、青砥（押上線・本線）、押上（押上線・浅草線）、泉岳寺（浅草線・京急）、堀ノ内（本線・久里浜線）の路線別IDを含める。成田スカイアクセス線経由ではない。
- 京急線内は既存group1173/type312の標準特急パターンを利用。既存1172・1173、全駅停車426を一切変更しない。
- 土休日の限定便を終日運転と誤認させないため、新規両type・groupにrequires_timetable=trueを指定。既存の日時なし経路探索・到達判定では除外し、手動選択用として提供する。共有種別のルールは変えない。
- type559/group1205は並行PR #1741・#1877で使用中。再採番余地として560/1206を空け、561・562/1207を使用する。マージ前に再確認する。

## 反映条件と検証

**将来変更なのでDraftを維持し、2026年11月21日より前にはdevにもマージ・配信しない。** 日付による自動表示切替はなく、requires_timetableは手動選択を隠す機能ではない。マージ・本番リリースは別作業。

回帰テストは全駅順・種別切替・各停区間・特急通過駅・接続駅ID・方向・運行制約、および既存1172/1173/426の維持を確認する。公式列車番号と発着時刻は根拠であり、時刻表データとして新たに配信するものではない。

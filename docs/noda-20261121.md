# 東武野田線 2026年11月21日改正

2026-11-02確認。[東武鉄道2026年10月16日発表（2ページ）](https://www.tobu.co.jp/cms-pdf/releases/20261015141245OBw85VzO_rZmXZuPsKRzJg.pdf)。

## 反映時期

この変更は2026年11月21日施行分。施行前はdraft PRに保持し、devにもマージしない。
マージするとステージングに自動配信される。現行スキーマには種別・系統の施行日による切替機能がなく、
requires_timetableだけでは手動選択用の駅一覧を隠せないため、施行前の公開を防ぐのはマージ時期の管理である。
マージ・本番反映は施行日以降に別途行う。本PRは自動マージ・リリースを設定しない。
マージ直前にdevのID重複と公式最終時刻表を再確認する。

## 登録内容

平日朝の柏→船橋5本（柏発6:31・7:00・7:31・8:02・8:32）。
全12駅を柏から船橋の順に登録。停車駅は柏・高柳・新鎌ケ谷・塚田・新船橋・船橋。
既存急行の該当区間の駅ID・順序を使用し、通過駅も保持する。

現行devの最大type_cd=558、最大line_group_cd=1204を確認し、
専用種別559「区間急行(船橋方面)」・系統1205を新規割当する。
共有種別319は方向0で大宮〜柏や他路線にも使われるため変更しない。
新種別は船橋への下り限定としてdirection=2、既存区間急行と同じkind=3・色を使用する。
type319/group333の大宮〜柏は公式発表どおり維持。直通を推測して両系統を結合しない。
alias、生成各停、既存の急行も変更しない。

曜日・時間帯限定を表すためtype559/group1205にrequires_timetable=trueを登録する。
日時を持たないconnectedRoutesと到達判定から除外し、手動選択の停車パターンとして提供する。
これは運行日カレンダーや便別時刻表の実装ではない。
乗降専用駅は発表されていないためroute_stop_rulesを推測で追加しない。

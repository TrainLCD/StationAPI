## 回帰検査

`cargo test -p data_validator --test keio_stopping_patterns` で、各行の種別と公式駅案内の停車種別を比較する。都営線内の各駅停車をグループ全体の種別として扱わず、京王区間の各行の `type_cd` を使用する。

既存31グループがすべて存在すること、および各グループの路線区間から求めた駅ID列がCSVの列と完全一致することも検証する。これにより行の削除、重複、並び違い、調布・北野・東府中・高幡不動・笹塚の接続部での片側ID欠落を検出する。井の頭線は別線区のためこの検査の対象外。

次の差異は公式の運行形態に基づくもので、均一化しない。

- [Mt.TAKAO号](https://www.keio.co.jp/zasekishitei/index_mt.html)の758は下り（新宿・明大前・高尾山口）、759は上り（府中以西の所定駅・明大前・新宿）。駅案内の停車種別一覧だけでは方向別の停車駅を表現できないため、グループ別の期待値を使用する。
- 京王八王子・高尾山口系統の特急は東府中を一部停車（`pass=5`）とし、競馬場線直通特急764は東府中の両路線IDで停車する。
- 相模原線の急行・特急、高尾線の急行・特急は各線の公式駅案内に従う。特急が高尾線内で各駅に停車しても急行の通過駅まで変更しない。

本検査は既存の停車パターンと駅列を対象とする。新系統の収録網羅性、時刻指定検索、乗降制限の実装を保証するものではない。公式案内には高尾線の京王ライナーも掲載されているが、現行CSVには専用の路線グループがなく、系統追加は別途対応が必要。

# 関西の非JR駅の座標監査（2026-11-06）

## 対象と方法

`data/3!stations.csv` の `pref_cd=24..30`（三重、滋賀、京都、大阪、兵庫、奈良、和歌山）、
`e_status=0`、路線の会社が `company_type!=1` の1,304行・32事業者を対象とした。
私鉄に加え、地下鉄・第三セクター・新交通も含む。県外の駅、廃止駅、JRは対象外。
路線ごとの駅レコードを数えており、物理的な駅の数とは異なる。

照合元は国土交通省の[国土数値情報・鉄道2025年度版](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html)
（2025年12月31日時点）の `N02-25_Station.geojson`。
駅名の表記差（難波/なんば、我孫子/あびこ、中百舌鳥/なかもず、鴬/鶯、副駅名等）を吸収し、
事業者名を対応付けた。神戸高速線は運行事業者の駅形状も照合した。
Osaka Metroは路線も一致させ、同名の別路線ホームへの誤一致を避けた。
他社の複数路線にまたがる候補も、個別確認時に路線を区別した。

既存の座標から駅LineStringの各線分への最短距離を計算した。
距離は局所平面近似（緯度1度=111,320m、経度にcos緯度を乗算）による概数。
事業者一致・Osaka Metro路線一致で50m超は40行、100m超は16行だった。
新長田の海岸線は最寄りの山手線ではなく海岸線に照合し直すと約94mとなる。

差があることだけを誤りとはせず、候補を近鉄、京阪、その他に分けて調査し、
事業者公式地図・構内図・自治体の移設資料・[地理院地図](https://maps.gsi.go.jp/)と比較した。
駅出入口とホーム、駅共通の代表点と路線別ホームの差もあるため、N02への一律置換は行わない。
今回の監査は大きな位置ずれの抽出と候補の確認であり、全駅の測量精度を保証するものではない。

公式に測量された単一の「駅座標」という意味ではない。

## Osaka Metroの既存修正との統合

初回監査では野田阪神・鴫野の修正も作成したが、PR準備時に `dev` の
[#1763](https://github.com/TrainLCD/StationAPI/pull/1763) で両駅を含む18行が
路線別ホームの代表点へ修正済みと分かった。これらは既存修正を維持し、本PRのCSV差分から除外した。
初回に保留したOsaka Metroの他16行も同PRで修正済みのため、保留一覧から除外する。
詳細は [Osaka Metroの監査記録](osaka-metro-coordinate-audit.md) を参照。
冒頭の1,304行・距離しきい値の集計は、同PR適用前の `df61185` に対する初回監査の結果である。

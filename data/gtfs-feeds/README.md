# 追加バスGTFS

フィードごとに `zz_gtfs_<連番>_<地域名>.json` を追加します。
ファイル名は路線・停留所の永続IDに使うため、追加後は変更しないでください。
連番は、既存の設定の後に並ぶ値を選びます。

`excluded_route_ids` には、運休などで取り込まない `routes.txt` の `route_id` を指定できます。
該当する路線・便・停車時刻を除外します。運行再開時に見直せるよう、フィードの出典ページに理由と確認日を記録してください。

`name` はフィード名、`url` は現行ZIPのHTTPS URL、`source` は配布元、
`license` は利用条件です。 `company_cd` は事業者コードです。
既存事業者のときは `company` を省略します。新規事業者には
`company` で `name`、`kana`、`english`、`url` を指定します。
正式名称が `name` と異なる場合は `name_full` に指定します。
省略すると `name` が正式名称にも使われます。
同じ事業者の複数のフィードは同じ定義を使えます。

`allow_routes_without_trips` を `true` にすると、便が設定されていない路線を除外します。
季節路線を路線一覧に残すフィード向けの設定です。便はあるが停車順がない路線は引き続きエラーになります。

`https://api.odpt.org/` のフィードには既存の `ODPT_ACCESS_TOKEN` を使います。
展開済みのキャッシュは `data/gtfs-cache/<設定ファイル名から拡張子を除いたもの>/` に置きます。

`normalization: "daito_2026"` は、大東市の令和8年度配布原本に限った補正です。
`trips.txt` の Shift_JIS を UTF-8 に変換し、欠けている末尾任意列を空欄で補います。
`stops.txt` の総合文化センター3行にある小数点のカンマだけを修正します。
想定外のヘッダー・列数、UTF-8でもShift_JISでも復号できないバイト列はエラーとし、他フィードのCSV検証を緩めません。
原本修正時にはこの設定を見直してください。
